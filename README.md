# CodeAlpha Machine Learning Projects

# Projects

# 1. Iris Flower Classification

This project uses machine learning to classify Iris flowers into different species based on their sepal and petal measurements.

# Algorithm Used
- Decision Tree Classifier

#Features
- Sepal Length
- Sepal Width
- Petal Length
- Petal Width

# Dataset
- Iris.csv

# Evaluation
- Accuracy
- Confusion Matrix
- Classification Report


# 2. Car Price Classification

This project classifies cars into Low, Medium, and High price categories using car-related features.

# Algorithm Used
- Decision Tree Classifier

#Features
- Year
- Present Price
- Driven Kilometers
- Fuel Type
- Selling Type
- Transmission
- Owner

#### Dataset
- car data.csv

#### Price Categories
- 0 = Low Price
- 1 = Medium Price
- 2 = High Price

# Evaluation
- Accuracy
- Confusion Matrix
- Classification Report
